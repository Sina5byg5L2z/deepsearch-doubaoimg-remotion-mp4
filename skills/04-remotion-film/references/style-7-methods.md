# 代码画视频 · 7 种风格方法论（普适性总结）

> 来源：7 张提示词模板截图（2026-10-03）。只提取风格与制作方法，场景示例已剥离。
> 核心思想一句话：**所有画面自己写代码画，零图片素材、零模型文件，最后渲染成 MP4。**

---

## 一、七种模板共同骨架（普适结构）

每条提示词都由 7 个标签构成，这个结构本身就是方法论：

| 标签 | 作用 | 普适要点 |
|---|---|---|
| `<role>` | 给 AI 一个手艺人身份 | 身份决定审美取向（像素美术师在乎干净、绘本插画师在乎手作感、动效设计师在乎节奏） |
| `<context>` | 说明播放环境 | **永远是"横屏口播视频素材，观众在手机上看"**——手机上看得清是唯一北极星 |
| `<task>` | 一个具体场景 | 只讲一件事，画面元素少而大 |
| `<specs>` | 硬性技术指标 | 1920×1080 / 30 帧 / 8–30 秒 / 配乐代码合成 120BPM / 渲染成 MP4 |
| `<style>` | 真正的风格核心 | 克制的颜色、克制的字体、有纪律的动效（见下） |
| `<avoid>` | 反 AI 味清单 | 所有模板共用同一份黑名单（见第三节） |
| `<check>` | 自检闭环 | **抽 5 帧拼成一张图逐条检查，有问题改完再交**——QA 内置于提示词 |

## 二、七种风格的核心制作方法

### 1. 像素风
- **技法**：Canvas。先在很小的画布上画（横屏 192×108，竖屏 108×192），**整数倍放大 + 关掉平滑**，所有坐标取整——每个像素都是清晰的方格。
- **颜色**：不超过 16 种。
- **动效**：人物一只只换姿势（约 10 帧一轮）；火、烟、水这类每帧都倾动；**每一帧只动一样东西**，节奏像老游戏。
- **自检**：缩到手机大小主角还认不认得出、颜色有没有超 16 种、首尾帧接不接得上（能循环）。

### 2. 老电视
- **技法**：**两层合成**。第一层照常画像素画（256×144）；第二层把整个画面当纹理，叠一层老电视着色器：弧形屏幕、扫描线、荧光点阵、泛光、暗角、轻微闪烁。
- **关键纪律**：第二层只是给现成的画面套一块旧屏幕，**不要重画**。
- **自检**：套上效果后主角还认不认得出、泛光有没有把形状糊掉、弧形屏幕边有没有切到主角。

### 3. 手绘绘本
- **技法**：p5.js + p5.brush 笔刷：纸张纹理的底、铅笔勾线、水彩上色。
- **帧率**：**一秒只换 12 张**（12fps），每条线条轻轻抖一下——手绘动画的生气全来自这种抖。
- **自检**：主角比例对不对、氛围够不够（要一眼看得出来）、线条有没有在抖。

### 4. 3D
- **技法**：Three.js，柔和的光和影子。主角只用**方块、圆柱、球这些基础形状拼**——因为代码搭不出照片那么真的实物。
- **镜头**：要一眼看出是真 3D，镜头要动，近处远处要分得开。
- **自检**：模型有没有破洞、穿模或悬空，缩到手机大小主角够不够大，镜头动得顺不顺。

### 5. 产品宣传片
- **技法**：HTML/CSS/SVG。浅色背景，黑白组件 + **一个强强调色**。
- **动效**：所有位置、大小、圆角的变化都用**弹簧动画，到位时轻轻弹一下**；每次变化都由**光标去点、去拖**，像真人在操作；变化卡在**配乐的半拍上**。
- **自检**：有没有零件飞出卡片、光标做的东西对不对得上、变化是不是都落在拍子上。

### 6. 知识科普
- **技法**：印刷排版风：暖白纸底、黑字、**只用一个强调色**、大号年份。节点像翻日历一样一页页换，底部一条时间尺，标记跟着走。配乐 120BPM，**节点翻落在拍子上**。
- **事实纪律**：这是七种里唯一带"内容审查"的——日期和事件**逐条到官方来源核实，核不到的不写**。
- **自检**：完整逐页抽帧查错字、日期标题对不对得上、翻页（不是卡片）、每句话能不能在来源里找到依据。

### 7. 随它发挥（自由动效）
- **配色**：只用黑、米白和一个亮橙色，米白底；**一种标题字体、一种正文字体**。
- **动效**：每个场景用**一种不同的动效手法**（大字拆开重组、图形变形、粒子、镜头穿越…），把最拿手的都用上。
- **节奏**：每个场景只讲一件事，字少而大；**开头一秒就必须有东西动起来**；分 5 个场景，每 2–3 秒换一个，场景切换卡在拍子上。
- **自检**：字有没有出画、有没有空白帧、切点卡不卡拍、看完一整遍节奏和幅度别削顶。

## 三、共用反 AI 味黑名单（`<avoid>` 的交集）

几乎所有模板都在禁同一样东西：

1. **渐变、模糊、发光、半透明**——AI 味第一来源（像素风、老电视、3D、科普、自由发挥全禁）
2. **所有东西一起淡入淡出**——最典型的"AI 动效"
3. **满屏小字**——手机上看不清的东西一律不上
4. **渐变按钮**（产品类）
5. **紫色霓虹、镜头乱晃**（3D 类）
6. **已有的游戏角色 / 角色 IP / Logo**——不碰任何现成 IP
7. **画面里写字**（像素/老电视类，招牌只画图形）

## 四、普适制作原则（跨风格提炼）

1. **纯代码作画，零素材**：Canvas / p5.js / Three.js / HTML+CSS+SVG，不用任何图片和模型文件。
2. **配色极简**：像素≤16 色，其余全是「黑白 + 1 个强调色」。颜色是风格，不是装饰。
3. **字体极简**：一种标题字体 + 一种正文字体，没有第三种。
4. **动效有纪律**：一次只动一样东西；一切变化卡在 120BPM 配乐的拍子（或半拍）上；弹性动画带轻微回弹；手绘感靠 12fps + 线条抖动。
5. **手机优先**：所有自检都包含"缩到手机大小还认不认得出"。主体要大、字要大、元素要少。
6. **纹理用叠加层，不重画**：质感类效果（旧电视、纸张）都是"画一层 + 套一层"，两层解耦。
7. **程序化配乐**：120BPM 代码合成，动效节点落在拍子上——画面和声音同源，天然同步。
8. **QA 内置**：抽 5 帧拼一张图逐条查 + 完整逐帧拍一遍查错字/空白帧/切点，**改完再交**。
9. **循环与首尾**：短片注意首尾帧衔接（能循环播放）。
10. **一场景一事**：每个场景只讲一件事，字少而大，开头 1 秒必须有东西动。

## 五、映射到本机工具链（Remotion 落地要点）

本机已有 Remotion + ffmpeg 成片流水线，7 种风格均可落地：

| 风格 | Remotion 实现要点 |
|---|---|
| 像素风 | Sequence 内用 Canvas 逻辑画到 192×108 的 offscreen，再 `imageRendering: 'pixelated'` 整数倍放大；帧动画用 `useCurrentFrame()` 取整换姿势 |
| 老电视 | 画完的内容层之上叠 SVG/CSS 扫描线 + 暗角 + flicker（opacity 每帧微扰），`mixBlendMode` 合成 |
| 手绘绘本 | `fps=12` 的 Composition（或 everyNthFrame=2），线条位置加 per-frame 伪随机抖动（seed 固定），纸纹底 + multiply |
| 3D | three.js 场景进 Remotion（@remotion/three），柔和平行光 + 阴影，镜头用 interpolate 匀速运动 |
| 产品宣传片 | spring() 自带回弹；光标用一个绝对定位的 SVG 指针按时间轴补间；变化点对齐 BPM 网格 |
| 知识科普 | 页面节点按 `Math.floor(frame / pagesPerBeat)` 翻页；时间尺 SVG；数据先核实再上屏 |
| 自由发挥 | 每幕一个独立 Sequence + 不同转场手法；配乐先合成，BPM 网格决定所有切点 |

**通用 QA（对齐模板的 `<check>`）**：渲染后 ffmpeg 抽 5 帧拼网格目检 + 完整过一遍查空白帧/切点/错字，修复后再交付——与本会话已有的抽帧 QA 流程一致，可直接沿用。
