代码画视频 · 7 种风格样板

Agent 做视频前，把本页展示给用户选风格。所有画面由代码绘制（Remotion 落地），零图片素材、零模型文件，渲染成 MP4。点击卡片右上角「选这个」高亮你的选择。

Agent 使用说明（BLOCKING）：项目一开始就 present 本页并让用户选定风格，确认后把「风格编号 + 主题适配说明」写进工程约定再动工。 禁止先开工中途再问——风格返工 = 全片重渲。用户也可以指定多个候选，让 Agent 先出 3 张主题适配样张后再拍板。

01像素风

小画布整数倍放大 + 关平滑，≤16 色，每帧只动一样东西，节奏像老游戏。适合：游戏话题、复古科技、数据年代感。

02复古电视风

内容层之上叠扫描线 / 暗角 / 荧光辉光 / REC 角标，两层解耦不重画。适合：怀旧题材、乐史回顾、年代叙事（实战定稿风格）。

扫描线 + 暗角 + 辉光 mixBlend 叠加

03手绘绘本风

纸纹底 + 钢笔勾线 + 局部淡彩，12fps 换帧、线条每帧轻抖。适合：科普叙事、人物故事、温暖治愈系选题。

p5.brush / SVG 抖动线 + 淡彩色块

07自由发挥（自由动效）风
