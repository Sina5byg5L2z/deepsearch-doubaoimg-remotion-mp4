# Issue Tree 问题拆解规程（麦肯锡法）

> 本文件是 video-research skill 的 [建议] 级参考。标准专题按此执行；快查型可跳过。
> 目标：把模糊的大问题拆成「可独立回答、可挂具体证据」的子问题集。

## 操作规程

- **根问题先改写到精确可判**：模糊的根问题产出无用的树。
  「为什么 X 没有成为 Y」→ 先钉死 Y 的定义与差距项，再改写为
  「差距被什么生产出来（主动选择 / 结构限制 / 时代窗口，各占多少权重）」。
- **MECE 拆第一层**：2–4 个分支；同层只用一种切分逻辑；互斥（不重叠 → 证据不重复计票）+
  穷尽（无遗漏 → 答案必在树上）。**MECE ≠ 有洞察**——每层至少试两种切法再定。
- **只切 2–3 层就停**：切到「能挂上具体证据/数据」的粒度即可。
- **区分树型，禁止混搭**：诊断树（why，分支=候选原因）、方案树（how，分支=候选手段）、
  假设树（先给 day-one 答案再拆「要成立需要什么」）。混用 = 把原因当方案。
- **假设先行**：每个优先分支写一句**可证伪**的假设，并先设计「什么证据能杀死它」——
  调研是去杀假设，不是去找支持。
- **80/20 排序**：按 impact × workability 给分支定级，大部分答案通常集中在 2–3 个分支；
  其余显式搁置并写一行搁置理由，禁止平均用力。
- **迭代重画**：证据杀死/证实分支后重画树；合成结论前检查**分支间相互作用**
  （A 分支的结论可能推翻 B 分支，拆解会隐藏跨分支联动）。

## 子问题产出标准（拆完自检，也是派子 Agent 的准入）

每个子问题：可独立回答、有可挂的证据类型、合起来 MECE 覆盖根问题、互不重叠。
