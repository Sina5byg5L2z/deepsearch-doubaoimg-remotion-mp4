# 调研报告成稿技艺（10 条 + 结构模板）

> 本文件是 video-research skill 的 [建议] 级参考。框架只保证方向和结构，成稿差距在以下技艺。
> 写作范本：[`exemplar-调研报告-radwimps.md`](exemplar-调研报告-radwimps.md)
> （RADWIMPS 案例，用户多轮调教后定稿，写作时逐条对照）。

## 10 条技艺

1. **坐标系拆解修问题**：不要把 Y 当单一标量。先拆出 Y 的多个坐标系
   （作品影响力 / 国民日常度 / 出海…），逐坐标系定位 X——差距常只存在于部分坐标系
   （例：RADWIMPS 在乐迷坐标系就是顶流，差的只是国民日常度），问题精确化为
   「为什么跨不过那一个坐标系」。
2. **中心论点先行**：开工前先立一句可记忆的中心论点（"不是不够红，而是红错了坐标系"式），
   全篇围绕论证它；证据推翻论点就改论点，不迁就。
3. **机制按确定性排序 + 混杂变量声明**：每条机制 = 标题即结论 + 论证 + 确定性标注；
   相关落差不能单一归因时明说「含疫情/成员变动等混杂变量，取结构性推断而非因果证明」。
4. **裁决流行假设**：对流传说法单独裁决（"同音作曲=旋律单调" → 「现象对，结论错」），
   裁决比新发现更有说服力。
5. **跨时间一致性检验**：判断"姿态还是禀性"用多年份一手引语对齐——口径零漂移才允许写「禀性」。
6. **分布对照实证**：多来源数据并排成对照表（粉丝票选 vs 大众收藏 vs 官方榜 vs 实时收听），
   让机制变成可验证的「坐标分裂/倒置」分布；孤立单点数据不引用。
7. **盲区候选假设清单**：用户点名维度之外，自主列候选假设逐个验证（事务所约束/作品哲学/
   feat. 稀释/解禁滞后…）；拆不开的明写「从现有证据无法拆分」；初版判断有错的在正文记录修正过程。
8. **证据强度分级 + 反向案例**：影响谱系按 A（本人原话+行为证据）/ B（官方名单）/
   C（直接输出）/ D（行业俗谚）分级；主动写反向案例划边界（哪些人的影响链不经过 X）。
9. **衍生问题主动覆盖**：预判用户会追问的衍生问题（老粉为何偏爱老歌？新歌同质化吗？）
   逐个「裁决式」回答，不等追问。
10. **收束单根 + 反证公允**：所有机制汇聚到同一个主观内核；下总结论前先列反证坐标系
    承认 X 在自己坐标系的成就；一句话总结要能直接复述、可作视频标题。

## 报告结构模板（照此排布）

先修问题（坐标系表）→ 事实底座（编号证据）→ 机制归因（确定性排序）→
深挖章（技法裁决 / 态度引语表 / 受众机制 / 因果时间线 / 时代对照 / 衍生问题裁决）→
自主盲区章 → 反证与公允结论 → 地位谱系（A-D 分级 + 反向案例）→ 一句话总结。

因果时间线用「阶段 | 事件 | 成为下一步的因」三列表——每一环必须能指出来自事实卡片的支撑，
「无环需假设补齐」才算闭环。
